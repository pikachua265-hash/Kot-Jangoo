# Kot Jangoo - House of Taste & Royal Heritage Hotel App

A high-end, responsive hotel & restaurant web application designed for **Kot Jangoo** ("House of Taste"), featuring its signature castle architecture, night illuminations, interactive table & seat booking system, room reservations, and culinary menu.

---

## 🌟 Key Features

1. **🏰 Home Screen**
   - High-impact hero banner incorporating actual night photography of the illuminated fort architecture and neon tower.
   - Quick reservation shortcuts, chef specialties, royal amenities, interactive guest reviews, and high-resolution photo gallery review modal.

2. **📜 Royal Dining Menu**
   - Categorized cuisines: *Desi Ghee Karahi & Handi, Charcoal BBQ & Grills, Imperial Platters, Clay Oven Breads, Traditional Desserts, Beverages & Kashmiri Chai*.
   - Live search filter, spicy indicators, portion badges, preparation times, and instant "Add to Order" functionality.
   - Live sliding cart drawer with total calculations in PKR.

3. **🪑 Interactive Table & Seat Booking System**
   - **4 Fortress Zones**: *Starry Castle Courtyard (Open Air), Royal Fortress Rooftop (Tower View), Imperial Heritage Hall (AC), VIP Gazebo Cabanas*.
   - **Visual Floor Map & Seat Selector**: Real-time table status (Available in Emerald/Gold, Selected in glowing Amber, Booked in Muted Slate).
   - Capacity display, chair placement visuals, reservation time slots (Lunch, High Tea, Prime Night BBQ, Late Night), and special occasion requests (Birthdays, Candlelight setups).
   - Generates instant verified digital reservations with QR code confirmation passes.

4. **🏨 Hotel Room & Stay Booking System**
   - Suite listings (*Fortress View Royal Suite, Imperial Grand Chamber, Heritage Family Castle Suite, Deluxe Pavilion*).
   - Check-in / check-out calendar pickers, guest counters, luxury amenities breakdowns, pricing per night, and guaranteed booking confirmation.

5. **📱 Bottom Navigation Bar & Mobile App Simulator**
   - 5-tab docked bottom navigation: **Home**, **Menu**, **Book Table (Floating Action)**, **Stay/Rooms**, **My Bookings**.
   - One-click toggle between **Mobile Phone Simulator Mode** (with iPhone chassis & dynamic island) and **Expanded Fullscreen Web Mode**.

## 🚀 How to Open and Run

### Method 1: Double-Click Launcher
Double-click `launch_app.bat` to instantly open the application in your default browser.

### Method 2: Open HTML File
Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Brave, Safari).

### Method 3: Local HTTP Server (Python)
Run in PowerShell or Command Prompt:
```bash
cd "C:\Users\HAROON TRADERS\.gemini\antigravity\scratch\kot-jangoo-app"
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
